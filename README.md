# MusicBee Portable releases

Unmodified MusicBee Portable archive mirror.

- [MusicBee](https://getmusicbee.com/), developed by Steven Mayall (distributed under its own license)
- [MusicBee on Linux](https://github.com/fiso64/musicbee-linux), an unofficial Linux integration project

`versions.json` lists the mirrored versions and SHA-256 checksums.
